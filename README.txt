# ML Starter Project

This is a simple Machine Learning starter project using Linear Regression to predict marks based on hours studied.

## Files:
- `model_train.py`: Contains training, evaluation, and model saving code.
- `mymodel.pkl`: Generated after running the script.

## Steps to Run:
1. Open terminal in this folder.
2. Create virtual environment (optional):
   - `python -m venv venv`
   - `source venv/bin/activate` (macOS/Linux)
   - `venv\Scripts\activate` (Windows)
3. Install required libraries:
   - `pip install pandas scikit-learn joblib`
4. Run the training script:
   - `python model_train.py`
